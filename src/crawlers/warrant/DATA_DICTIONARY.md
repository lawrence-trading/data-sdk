### 1.2 事件日的語意差異（建 SCD2 時最重要）

| 來源 | 事件日代表 | 精度 |
|---|---|---|
| M-adj / M-reset | **生效日**——新履約價從這天起適用 | 精確 |
| T-adj `重設` 列 | 生效日（與 M-adj 同一事件比對一致） | 精確 |
| T-adj `上市櫃` 列 | 發行日，**早於上市日 2–4 天**；作為 issuance 事件應改用 `上市日` | — |
| M-ann `輸入日期` | **公告日**——市場得知之日，早於生效日數天（提前到期例：公告 08/05，最後交易 08/06，到期 08/10） | 精確 |
| M-snap diff | 爬取日 | ± 爬取間隔 |
| T-basic/T-adj 的 `預定≠實際` | **無日期**——只知道變過 | 未知 |

BSM 定價要的是「當時市場已知的到期日」→ 到期日事件的 `effective_date` 應取**公告日**（M-ann），不是生效日。

## 2. 重設 vs 調整

### 2.1 定義

| | 重設 (reset) | 調整 (adjustment) |
|---|---|---|
| 觸發 | 重設型權證依發行條款，在觀察期（通常上市前二營業日至上市日）依標的收盤價**重設**履約價；一檔一生一次，98% 生效於上市日 | 標的除權、除息、減資、現增 → 依交易所公式調整履約價與行使比例，**K × ratio 守恆**（實測中位數漂移 0.58%，81% 在 1% 內）；一檔可多次 |
| 影響欄位 | 履約價（上下限型連上/下限） | 履約價 + 行使比例（上下限型連上/下限） |
| 哪些權證 | `權證衍生種類 == 重設型`：37,945 檔（9%） | 所有權證，只要標的有除權息 |

### 2.2 各 dataset 的名稱

| | M-adj | M-reset | M-ann `公告種類` | T-adj `事件說明` | T-basic |
|---|---|---|---|---|---|
| 重設 | — | 整張表；`original_strike → reset_strike`, `reset_effective_date` | `4` 重設履約價 | `重設` ⚠ | `權證衍生種類`=重設型；`實際重設日`、`重設說明*` |
| 調整 | 整張表；`latest_strike/ratio/cap/floor`, `adjustment_effective_date`, `has_cap_floor` | — | `6` 履約價及行使比例 | `重設` ⚠ | — |
| 初始狀態 | — | — | `1` 發行 / `2` 上市 | `上市櫃` | 全表 |
| 提前到期 | — | — | `11` 提前終止上市 | — | `預定最後交易日 ≠ 最後交易日` |
| 展延 | — | — | `9` 申請展延 / `10` 展延生效 | — | 同上（反向） |
| 註銷 | — | — | — （`t132sb11` 有累計數，無日期） | — | — |

⚠ **T-adj 把重設與調整都叫 `重設`**。314,778 列 `重設` 涵蓋所有履約價/比例變動，跟 M-reset 的 2,692 筆「重設型權證上市日重設」不是同一概念。要分辨：`年月日 == 上市日 且 權證衍生種類 == 重設型` → 真重設；其餘 → 調整。

### 3.3 什麼**不是** point-in-time（建 SCD2 時不能直接當 as-of 值用）

| 來源 | 非 PIT 欄位 | 為什麼 |
|---|---|---|
| M-basic | `latest_strike`, `latest_cap/floor`, `alloc_qty_per_1k`, `exercise_end_date`, `last_trade_date` | 首次爬取時的值，之後 cursor 擋住更新；名為 latest 實為「首爬當下」 |
| M-basic | `original_strike/cap/floor`, `list_date`, `exercise_start_date` | 是 PIT（發行時值），但 19,889 筆壞 |
| T-basic | 全部 63 欄 | 2026-08-12 匯出當下的最終狀態；`目前履約價`、`目前行使比例`、`到期日`、`最後交易日` 都是終值 |
| T-adj | 50 個靜態欄（`到期日`、`最後交易日`、`預定最後交易日`、`目前履約價`…）**每列複製終值** | 同一檔跨事件列 `nunique = 1`；只有 `年月日`/`序號`/`履約價(元)`/`行使比例`/`事件說明` 是該事件當下的值 |
| T-adj | `目前行使比例` | 例外：**跟著該列 `行使比例` 走**（172,167 檔跨列不同），非終值也非靜態，別用 |

## 4. 對 SCD2 設計的直接含意

1. **T-adj 是履約價/比例的歷史主幹**，M-adj 只是 2026-09-01 之後的續集。反過來（M 為主、T 補洞）不成立——M 只有 5%。
2. **到期日必須是 SCD2 的隨時間欄**，事件來源要另外爬 `t95sb01`（`type=11` 提前終止、`9/10` 展延），`effective_date` 用公告日。
3. T-adj `上市櫃` 列當 issuance 事件時，`effective_date` 改用 `上市日`，不用 `年月日`（發行日）。
4. T-adj 靜態欄一律丟棄，靜態屬性從 `dim_warrant`（M-basic 修補版）取；`目前行使比例` 絕對不用。
5. `M-snap` 是唯一能讓 `dim_warrant` 的到期日/`latest_*` 不腐爛的機制，優先於一切歷史回填。
6. 待測：`t95sb01` 往回能查幾年。決定 3,055 檔歷史提前到期能否拿到真公告日。
